# Hestia 640→1280：回退集中于中段关节与末段开合事件

本地保存数组分析已完成。新增定位是：**双夹爪净 MAE 回退的 92.25% 来自
最后 10 槽；左关节净回退主要由场景 13 拉高，右关节回退更分散。**
1280 在全部五个开发场景预测了左夹爪越过 0.5 的开度，而记录目标只有场景
22 出现该事件。视觉泛化仍未修复；这些结果不能证明唯一根因或闭环失败机制。

比较固定为同一 Hestia 的 640/1280 保存点、40 train / 5 dev、frame-0 预测的
全部 50 个槽、四种原推理噪声。窗口、分母、阈值和方法在本轮首次计算前固定；
此前已看过总曲线，所以这是开发诊断，不是独立验证或 checkpoint 选择。
四噪声不是四次独立训练。以下先逐噪声算误差，再取算术平均。

## 1. 首动作与完整 chunk 的变化不同

| 开发指标 | 640 | 1280 | 1280−640 |
|---|---:|---:|---:|
| 左关节完整 MAE（rad） | 0.058508 | 0.061673 | +0.003165 |
| 右关节完整 MAE（rad） | 0.057942 | 0.062214 | +0.004273 |
| 左关节首动作 MAE（rad） | 0.019339 | 0.014665 | −0.004674 |
| 右关节首动作 MAE（rad） | 0.021705 | 0.022049 | +0.000344 |
| 双夹爪完整 MAE（0–1） | 0.058500 | 0.066347 | +0.007847 |
| 双夹爪末 10 槽 MAE（0–1） | 0.194572 | 0.230766 | +0.036195 |

左右关节完整 MAE 均在四噪声下回退；左关节首动作却四噪声全部改善。
右关节首动作平均略差，但单噪声两好两差。当前 adapter 每轮只执行 chunk
首动作，因此不能把末段离线失配直接等同于闭环实际执行了错误开合。

训练集完整关节 MAE 同期从 0.025483 降至 0.016774，双夹爪从 0.025663 降至
0.016500；本轮结果与此前训练拟合增强、开发回退的证据吻合。

## 2. 哪些场景贡献了回退

下表按完整 50 槽计算，保留全部五个开发场景，不筛选失败样本。

| episode | 左关节 640→1280 MAE | 右关节 640→1280 MAE | 双夹爪 640→1280 MAE |
|---:|---:|---:|---:|
| 22 | 0.062819→0.058557 | 0.095648→0.098360 | 0.166114→0.146556 |
| 13 | 0.070211→0.088569 | 0.051527→0.062207 | 0.012590→0.024004 |
| 7 | 0.049525→0.045792 | 0.033526→0.035429 | 0.023709→0.037213 |
| 33 | 0.060201→0.060956 | 0.051000→0.054446 | 0.050833→0.073992 |
| 45 | 0.049784→0.054491 | 0.058008→0.060630 | 0.039256→0.049972 |

贡献定义为该场景的 MAE 变化除以固定场景数 5，五项严格相加为整体变化。
episode 13 贡献双臂关节净回退的 78.09%、左关节净回退的 116.01%；后一个数
超过 100% 是因为场景 22/7 的改善抵消了部分退化，不能解释为样本占比。

去掉 episode 13 后，左关节变化均值变为 −0.000633 rad，三个噪声改善、一个
回退。因此“左臂每个场景都随拟合恶化”不成立。但双臂关节仍四噪声回退，
平均 +0.001019 rad；右关节去掉任一场景后均四噪声回退。双夹爪去掉任一
场景后也四噪声回退。上述删除一行计算只是敏感性分析，不改变数据 split。

逐维定位中 `left_wrist_angle` 是左关节回退最大的正贡献项。episode 13
这一维 MAE 为 0.137681→0.189833 rad，差 +0.052152 rad；其余五个左关节
平均 MAE 也全部回退。它不是单一坏维度足以解释的整体故障。

## 3. 关节回退不是仅由末槽拉高

| 固定槽区间（零基） | 双臂关节 MAE 变化（rad） | 双夹爪 MAE 变化（0–1） |
|---|---:|---:|
| 0–9 | −0.000754 | +0.001047 |
| 10–24 | +0.006318 | +0.001166 |
| 25–39 | +0.004527 | +0.000163 |
| 40–49 | +0.003081 | +0.036195 |

这是区间自身 MAE 变化；计算其完整 chunk 贡献时乘区间长度/50。双夹爪
40–49 槽贡献 +0.007239，占总净变化 +0.007847 的 92.25%。右夹爪该区间
贡献甚至超过总净变化，因为 10–39 槽平均改善。双臂关节该区间只占净回退
16.57%，不能用夹爪末段问题统一解释关节错误。

场景去均值 MSE 恒等式还给出左关节变化（rad²）：

`+0.001189432 = +0.000512573（预测方差） +0.000753101（−2×协方差） −0.000076242（共同偏差平方）`。

左关节与目标的场景相关在 640 为 −0.021～0.084，在 1280 为 −0.143～−0.040；
协方差项在四噪声均变差。右关节相关也从 0.164～0.238 降到 0.075～0.153，
且共同偏差增大。它们都没有呈现“更强响应同时得到正确跨场景对应”。
这些是五场景内的描述性分解，不证明视觉表示缺失或某个学习改动必然有效。

## 4. 夹爪：场景与开合事件对应失配

合同开度为 0 闭合、1 张开。辅助阈值固定为 0.5，表中是预测 chunk 内首次
向上越过阈值的槽位；`无` 表示 0–49 未发生，不能补写成第 50 槽。四个槽位
按 zero / 20260905 / 20260906 / 20260907 排列。

| episode | 左夹爪目标越阈槽 | 1280 左夹爪预测越阈槽 | 目标末值 | 1280 预测末值范围 |
|---:|---:|---|---:|---:|
| 22 | 42 | 46 / 48 / 48 / 49 | 0.969698 | 0.591129–0.796030 |
| 13 | 无 | 47 / 49 / 49 / 49 | 0.164399 | 0.513959–0.797995 |
| 7 | 无 | 46 / 48 / 49 / 49 | 0.407455 | 0.508260–0.726492 |
| 33 | 无 | 45 / 48 / 48 / 49 | 0.181470 | 0.537052–0.849498 |
| 45 | 无 | 45 / 48 / 48 / 48 | 0.224622 | 0.594010–0.813710 |

1280 在所有开发图像都给出末段左夹爪张开事件，目标却只在 22 中出现；
在 22 中还晚了 4–7 槽（80–140 ms）。其他四场景的 16 个场景×噪声条件
均产生目标本段没有的阈值事件。它们是重复条件的描述，不能称 16 个独立样本。

右夹爪提供相反例子：目标在 22 的第 39 槽越阈，但 640/1280 所有噪声都没
越阈；在 33 的目标全段没有该事件，两个保存点却全部噪声都有。仅统一提前
或推迟动作没有充分依据同时修正这些相反方向的失配。

后置整理另用同一固定阈值检查 train40：目标左夹爪 14/40、右夹爪 6/40 出现
越阈，1280 预测的左夹爪假阳性为 1/0/0/0，右夹爪为 0/0/0/0；训练侧仍有
漏检。因此开发左夹爪全预测张开的现象不是“整个训练集都要求张开”的直接
结果。此计数是附加描述，不是原 Hestia 的新接受门，也未按 dev 调阈值。

**目前只定位到 chunk 内开合事件及幅度失配。** 50 槽后的实际开合时机、
非均匀时间变形、内部 sine latent 是否越出训练支持，本轮均未测。不能据此
断定是人工时序噪声、绝无未来开合、解码器错误或不可学习标签。
此前 ±200 ms oracle 的夹爪收益仍是有效历史证据，本轮没有否定它。
