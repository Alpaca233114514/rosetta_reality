# SmolVLA 数据优先科研诊断：无卡阶段结果

## 结论

本轮建立了可追溯、可独立复算的非隐藏数据包，修复审查清单遗漏和诊断数据的
来源/曝光记录缺口。时间戳、注册帧的独立像素读取及数值标签复算通过。
**尚不能确定视觉映射失败的唯一原因，也没有测得新的模型质量改善。**

当前仅获准无卡工作；实际设备检查为无 GPU。本轮不加载权重，GPU 用时、模型
推理、optimizer 更新和新增 Gate 均为0。沿用既有 step-5000 G3通过、G4 **0/5**
负结果；其中19次关节越界、38次非预期接触是逐仿真步累计值。
主对象未改变，未选择 checkpoint、启动新训练、下载新数据、提交或推送。

### 实际训练消费与重复监督

用原始 `schedule.json` 与 `model-ingress.json` 的完整20,000条记录核对实际消费，
然后独立复算每个动作帧的有效目标曝光；不是根据训练配置猜测覆盖。

| checkpoint | 输入曝光/唯一输入 | 主表已见训练输入 | 唯一监督目标帧 | 有效目标槽累计 |
| --- | ---: | ---: | ---: | ---: |
| 2500 | 10,000 / 10,000 | 83/160 | 19,962 | 475,689 |
| 5000 | 20,000 / 20,000 | 160/160 | 20,000 | 951,000 |

step-2500在0/125/250/375四个时点分别见过21/21/23/18个训练输入。
step-5000每个输入编号只出现一次，但相邻 chunk 使动作目标大量重复；目标帧
从 episode 开头到第49帧的监督次数逐步上升，此后每帧可获得50次目标曝光。
不同RGB图像数量也不能当作独立场景数量；本轮训练场景单位仍是40个 episode。

因此2500→5000同时增加更新数和输入覆盖。固定采样表可以描述学习过程，不能
独自确定“多训练”或“增加场景数”的因果作用。诊断输出显式保留已见标记，
不能把训练 split 中未见输入的误差统称为训练拟合误差。

## 代码审查与修复证据

旧清单按文件名关键词及绝对 import 追踪，会漏掉 `canonical_*`、相对/动态
导入和 shell 入口。保留旧 `inventory()`，新增完整相关目录的 `inventory_v2()`；
测试以 `canonical_entry.py` 和启动脚本复现遗漏，并检查嵌套报告覆盖。
最终清单覆盖1,422份相关文件，17个文件有本轮重点复核记录，41个文件包含需要
追踪的动态调用。每项带SHA、import、计算式调用及引用路径。清单是覆盖台账，
不是每份文件均已语义验收；未逐项闭合的内容明确标记，不能把原先“422份”
固定数字当作当前仓库的完整覆盖证明。

已沿实际路径核对：

```text
canonical_furnace(train) → smoke() → run_observed_launch
→ run_smolvla_v2(smoke, --plan smoke.yaml)
→ optimizer_smoke 配置（实际5000步、batch4）
→ explicit_sample_schedule → 原生 cycle/processor
→ SmolVLA policy.forward → 原生 flow loss → AdamW.step
```

`train`外层名称并不代表内部使用`training`阶段。实际8个 feature 包括训练集统计、
动作边界投影、显式全帧schedule和canonical RGB；没有另装 horizon loss 或视觉正则。
模型是 SmolVLA，视觉编码器冻结，expert与state projection可训练；50步chunk、每次
执行首动作。实际 AdamW LR=1e-4，betas=(0.9,0.95)，weight_decay=1e-10，clip=10；
cosine warmup16、decay5000、末端2.5e-6。记录依据为保存的 native config、feature
计划、模型入口与成功更新数，不以loss下降证明任务成功。

新增修复针对证据可信度：准确 parquet 来源；输入已见/目标曝光分开；按时间和
slot匹配train-only基线；逐episode统计；frame-0非视觉输入证明和自拷贝门禁；完整
预测、noise、mask保存；当前无卡计划在导入模型前拒绝采集。没有改动现有训练loss、
optimizer或Gate规则，因此不新增两步训练或重复G4。

既有真实CUDA反例与修复对照继续有效于原测试范围：CPU/CUDA像素缩放舍入曾导致
非零帧动作差异；canonical修复后episode49的0/249/499帧loss、155个梯度张量及
完整动作精确相等。证据见 `m2-smolvla-training-chain-canonical-result-2026-09-14.md`
和包内 `source-evidence/parity.json`。本轮没有重新加载模型，也不声称所有实现无错。

## 下一项最有信息量的实验

有卡且获得相应授权后，先对固定 **step-5000** 做一次完整视觉配对采集：
train40/dev5×四时间点×四共享noise条件，frame-0核验非视觉输入后由完整数组
计算所有非自身错配；后续时点使用预登记循环错图。左右关节/夹爪、首动作/完整
chunk分别比较正图、错图与train-only均值/中位数，并分解方差/协方差/均值偏差。

预计1268 forwards，无optimizer；先测吞吐，共享GPU硬上限3600秒、收尾留300秒。
step2500仅在step5000证据和预算确有需要时补相同采集；固定已见子群解释过程，
不选新checkpoint。若发现具体实现反例再登记两步更新对照。物理阶段注释和
视觉—state—action同步验证仍为独立缺口。无需先重跑相同G4或开启多炉搜索。
