# 固定插槽位置到左臂动作：首步与 chunk 末步

登记 `socket-action-horizon-20260911-001`。接续位置正对照通过后，隔离示范目标
时间位置：同一可见插槽位置是否更能预测第 49 帧左臂动作，而非第 0 帧动作。
49 是既有 50-action chunk 的最后索引（0.98 秒），不从开发结果选择偏移。

固定原 40 train / 5 dev，复用已逐图核验的蓝色插槽像素位置；不解码新图像、
不加载 K/V 模型或策略。只读相同缓存中 frame 0 和 49 的动作/state/timestamp，
Arrow 同时过滤 episode 与 frame，最多物化 90 行；hidden 不进入读取视图。
逐行核验 timestamp=frame/50，frame-0 动作须精确匹配前次读出。
仅初始插槽位置作为输入，frame-49 state 只检查有限值，绝不用于预测。

固定输入函数族：x/640、y/480 及其 x²、xy、y² 共五项二次多项式；标准化
只在各训练折拟合。任务只讨论插槽对应左臂的 6 个关节，左夹爪单独报告；
不预测右臂，不把单个物体位置当作整场景充分描述。
两个目标偏移各自按同样程序选择 ridge alpha，候选固定
`[0.000001,0.001,0.1,1,10,100,1000,1000000]`，seed=20260911，
train 五折、五外折/五内折；原混合单位 MAE 选择代理不变，正式判读按动作组。
不选最优开发偏移或忽略夹爪结果。分别选 alpha 是固定评估程序的一部分，
比较对象是两种监督目标的可读性，不声称模型权重只发生一次单参数变动。

主要判读是左臂关节 MAE / 对应 train 或 fold-train 最佳常数 MAE 的比值。
支持“末步更可读”须同时满足：

- 第 49 帧在 dev 和 nested 上的比值均小于 0.8；
- 两个比值均比首步对应比值小至少 0.2；
- 第 49 帧 dev 正确位置相对全部非自身位置平均 MAE 的收益大于 1e-8。

报告所有组、所有折和绝对误差。正结论只支持此物体位置与后续动作的关系
比首步更清晰，不能证明首步标签错误或完整观测下不可辨识；负结论也不能
证明标签无关，二次函数族、样本数量、另一物体/人的意图等仍有限制。
不修改训练目标、偏移动作标签、首动作执行合同或历史验收。

Linux Docker 固定原镜像，CPU 2 核，2 GiB 内存及 memory+swap，网络关闭，
上限 180 秒。check_env、Ruff、合成与原真实缓存检查通过后执行一次。
代码与输入 SHA 在同名 JSON 冻结。任何身份/时间戳/有限值失败立即停止。
输出新目录，数组 exact reload；不自动扫描更多偏移，不运行 policy 或 Gate。
