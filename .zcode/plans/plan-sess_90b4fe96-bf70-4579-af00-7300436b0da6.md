# SmolVLA 训练扩展层重做（新分支 `codex/smolvla-training-harness-v2`）

## 定性与边界（先说清楚）

- **重做对象**是 Rosetta 自己的训练组合层：5 个 `train_smolvla_*` monkeypatch 入口、5 个各自复制约 3000 行校验逻辑的 launcher、以及以 ~15 个 `ROSETTA_VLA_*` 环境变量充当隐形 plan 的隐式组装方式。`aster-b8-002` 正是被这种"只包住一层边界"的组装方式搞成无效实验的。
- **保留不动**：pinned LeRobot `lerobot-train`（revision `c903b114`）仍是唯一训练循环；`vla/horizon_loss.py`、`vla/state_robustness.py`、`vla/processor.py`、`vla/action_space.py`、`vla/fixed_samples.py` 语义不变，作为特性实现被复用；所有旧脚本、hash-bound 配置、`runs/`、`artifacts/` 是不可变证据，原样冻结。
- **诚实声明**：Gate 4 三连 `0/5` 的主因是方法层失败（T1/T2/T4），本重做不解决它、也不构成新炉授权。它的价值是让后续每个单变量实验（审计建议的 O2 梯度诊断、T7 resume parity、T3 噪声对齐等）在结构上难以再做错。

## 阶段 1 — 新包 `src/rosetta_reality/vla/training/`

**`plan.py` — 统一 typed plan schema**（替代各 launcher 里的 45 项析取 `_validate_plan`、70 行布尔 `_optimizer_contract`）：
- 分节字段：run identity、model/dataset/processor revision、Action Contract 引用 + checksum、optimizer/scheduler contract（沿用 Faust 语义：AdamW lr/betas/eps/wd/clip/warmup/cosine）、batch/steps/exposures、monitoring（含 T9 的 `save_freq % log_freq == 0` 校验）、resource budget、**有序 feature 声明列表**（引用注册表名 + 参数）、acceptance/停止条件、prerequisites（normalization identity、fixed-sample 证据）。
- 逐字段校验、报具体错误；fail closed。

**`features.py` — 特性注册表**（核心新设计）：
- `TrainingFeature` 声明：name、所属 plan 分节、`install(ctx)` / `restore(ctx)`、对 plan identity 的贡献。
- 迁移 8 个特性，实现尽量复用现有模块：
  1. `trackio_logging`（WandBLogger→TrackioLogger；为 `trackio_lerobot.py` 增加一个**公开的** experiment-config 注入函数，替代 `trackio_bridge._experiment_config` 私有补丁；旧文件只增不改语义）
  2. `train_only_statistics`（从 `train_smolvla_trackio._install_train_only_statistics` 迁入）
  3. `masked_camera_skip`（从 `_install_masked_camera_encoder_skip` 迁入）
  4. `action_boundary_projection`（从 `_install_projection` 迁入）
  5. `fixed_frame_sampler`（从 `_install_fixed_frame_sampler` 迁入）
  6. `horizon_weight_profile`（委托现有 `vla/horizon_loss.py`）
  7. `state_robustness_jitter`（委托现有 `vla/state_robustness.py`）
  8. `checkpoint_memory_trim`（新写一份设备无关实现，合并 `checkpoint_memory.py` / `checkpoint_accelerator_memory.py` 两份复制；旧两份冻结不动）
- 注册表保证：确定性安装顺序、double-install 拒绝、upstream SHA 漂移 fail closed、未声明/未知特性 fail closed。
- 环境变量只保留承载路径/secret；一切语义开关进 plan（默认 off）。

**`launch.py`**：plan → `lerobot-train` CLI argv 的唯一构造点（收编各 launcher 复制的 `_phase_arguments`）。
**`context.py`**：运行时上下文（plan、experiment config、roots、device、evidence 路径）。
